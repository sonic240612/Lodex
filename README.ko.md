# Lodex

[English](README.md) · [한국어](README.ko.md)

로컬 LLM과 OpenRouter를 위한 데스크톱 작업 공간.

## 실행

Node 24.11.1, npm 11.19.1, Rust 1.98.0, [Tauri 개발 환경](https://v2.tauri.app/start/prerequisites/) 필요.

```sh
git clone https://github.com/sonic240612/Lodex.git
cd Lodex
npm ci
npm run dev
```

Windows에서는 `run-lodex.bat`을 더블클릭해 개발용 앱 실행.

## 모델

- **내장 llama.cpp 관리:** 엔진 설치, GGUF 이어받기·분할 다운로드, 모델 프로필, 컨텍스트·생성 설정·GPU 레이어·KV 캐시·스레드·메모리 예약.
- **외부 서버:** llama-server, Ollama, vLLM, MLX. 외부 서버의 실행·종료는 사용자가 관리.
- **OpenRouter:** 모델 목록·컨텍스트 기본값, 계정 사용량, 요청 비용, 예산, 재시도, 비용 정산.
- **역할별 모델:** 계획·개발·서브에이전트·요약·검토 모델과 작업별 모델·비용 설정. 같은 대화 안에서 모델 변경 가능.

API 키는 [`.env.example`](.env.example)을 복사한 `.env` 또는 데스크톱 설정의 OS 키체인에 저장. 인증 정보·데이터베이스·모델·로컬 런타임은 Git 업로드에서 제외.

## 작업

- 로컬 프로젝트, 범위별 `AGENTS.md` / `CLAUDE.md` 자동 적용, 파일 검색·수정·검토·되돌리기.
- 한 번의 읽기 전용 조사에 `/plan`, 편집 가능한 할 일 목록, 완료 조건을 검증하며 진행하는 `/goal`.
- 독립 Git Worktree에서 작업하는 서브에이전트. 변경 페이지별 검토, 텍스트 충돌 해결, 바이너리 선택, 병합 되돌리기, 복구 가능한 보관.
- Docker·호스트 명령, 대화형 PTY 터미널, stdin/EOF, 백그라운드 작업, 취소, 실행 중 추가 지시.
- 웹 검색·페이지 읽기, 전체 접근에서 별도 Chrome/Edge 자동화, 등록한 언어 서버의 진단·정의·참조·설명·심볼 조회.
- 일정 간격·매일 지정 시각·프로젝트 파일 변경에 따른 예약 실행. 대화의 권한·모델을 사용하며 OpenRouter 사용 비용은 동일하게 발생.
- Telegram 계정 연결, 원격 대화, 승인·거절 버튼, 작업 제어, 답장 전달 기록.

일반 메시지는 Build로 실행. `/`를 입력하면 명령 목록을 표시하며 마우스 또는 방향키·Tab으로 선택. 주요 명령: `/plan`, `/goal`, `/resume`, `/stop`, `/compact`, `/quick`, `/skill`, `/new`, `/settings`.

## 컨텍스트와 연동

Eco는 작업 중 오래된 내용을 조금씩 LLM으로 요약. 큰 자동 압축은 약 80%부터 시작해 약 25%를 목표로 처리하며 보존할 지침과 모델 한도에 따라 결과가 달라질 수 있음. **컨텍스트 압축**은 LLM 요약, **빠른 압축**은 로컬 추출 방식. 별도 요약 모델 지정 가능. 요약 실패 시 원문 유지, 클라우드 요약 비용은 사용량에 포함.

전체 대화는 SQLite에 보관. ObservationPack은 큰 도구 결과를 저장하고 필요할 때 정확히 재조회하며, Action Fusion은 파일 변경과 후속 검증을 한 호출로 연결. [NVIDIA SoL-Pi](https://github.com/NVlabs/SoL-Pi)를 기반으로 적용한 기능으로 [라이선스 안내](THIRD_PARTY_NOTICES.md) 참고. 절감 효과는 모델·작업별로 측정 필요.

Codex, Claude Code, pi, OpenCode, OpenClaw, Hermes 형식의 로컬 Skills·MCP 설정 가져오기 지원. 스킬 직접 호출, 인자 치환, 도구 제한 적용. 가져오기만으로 스크립트나 훅을 실행하지 않음.

MCP는 stdio·Streamable HTTP·기존 SSE, 선택한 도구, 텍스트 리소스·프롬프트, JSON Schema 검증, OAuth PKCE·동적 클라이언트 등록, Sampling·Elicitation 지원. Sampling의 도구 호출은 요청한 서버에 반환하며 Lodex 도구로 실행하지 않음. 리소스 구독은 변경 알림을 표시하고 첨부 내용 갱신은 검토 후 반영. 이미지·음성·바이너리 모델 입력과 임의의 외부 에이전트 실행은 미지원.

## 데스크톱과 데이터

한국어·영어 UI, 라이트·다크, Liquid Glass·기존 디자인, 접고 펼치는 활동 기록, 마크다운, 컨텍스트 사용량·생성 속도 표시. 연동 기능은 설정 화면에서 관리.

창을 닫으면 트레이에서 계속 실행. 로그인 시 자동 시작은 선택 사항. **Quit Lodex**로 데몬과 백그라운드 작업까지 종료.

인증 정보를 제외한 백업 생성·내보내기·미리보기·복원. 기존 기록을 덮어쓰지 않고 없는 항목만 추가하며, 복원한 연동은 다시 활성화하거나 검토해야 함. 모델 파일·인증 정보·ObservationPack 원문 저장소·Worktree 폴더는 백업에서 제외.

## 개발

```sh
npm run check          # 타입 검사, 테스트, 프로덕션 빌드
npm run dev:web        # 임시 데이터로 UI 미리보기
npm run build:desktop  # 데스크톱 빌드
npm run evaluate -- --help
```

평가 도구는 분리된 임시 프로젝트에서 일반·Eco 모드를 비교하고 지정 시간 반복 실행 지원. 보고서는 Git에서 제외된 `.local/evaluations`에 저장. 클라우드 평가는 별도 허용과 비용 상한 필수.

CI 대상은 Windows x64, macOS ARM/Intel, Linux x64. 수동 **Desktop packages** 워크플로에서 설치 파일과 서명된 업데이트 생성. 서명에는 배포 인증 정보가 필요하며 개발용 미서명 빌드는 업데이트 비활성. 업데이트 설치 전 서명 검증·작업 종료·백업 확인.

개발 중인 앱으로 실제 OS 설치·접근성·GPU별 모델 성능 검증은 별도. 메모리 예산은 예약값이며 하드웨어 상한을 강제하지 않음. 모든 모델의 호환성·성능을 보장하는 것은 아님.
